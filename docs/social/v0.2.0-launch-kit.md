# prompt-sage v0.2.0 Launch Kit

## Positioning
`prompt-sage` is a token-efficient style layer for coding assistants: clearer Yoda cadence, strict literal preservation for technical text, and safe fallback behavior.

## What Shipped in v0.2.0
- Stronger Yoda voice with medium default readability.
- New heavy mode: `/sage roleplay`.
- Unified update command: `prompt-sage self-update`.
- Dry-run updates: `prompt-sage self-update --dry-run`.
- Token-efficiency behavior preserved and safety fallback unchanged.
